# Liquid Music — C# / Windows x64

Новая версия работает через `native/LiquidMusic.exe`. Python, локальный HTTP-мост
и расширения браузера не используются. Старая Python-версия, её зависимости,
тесты и папки расширений удалены из проекта.

## Запуск

Запустите `START_WIDGET.vbs`, `START_WIDGET.bat` или `native/LiquidMusic.exe`.
У сборки собственный .NET Runtime; Python и установка .NET не требуются.
Для интерфейса нужен Microsoft Edge WebView2 Runtime, уже присутствующий на этом ПК.
Настройки хранятся в `%LOCALAPPDATA%\LiquidMusic\settings.json`; прежний `settings.json` импортируется при первом запуске, включая голосовую клавишу **End**.
На новой установке голосовая клавиша по умолчанию — Num3.

## Отправка другу

Готовый архив: `dist/LiquidMusic-Portable.zip`. Отправляйте этот ZIP целиком.
Он содержит автономное приложение и модель голоса с чистыми настройками,
без ваших журналов, настроек, данных WebView2 и параметров подключения к браузеру.
Друг распаковывает архив, запускает `LiquidMusic.exe` или `START_WIDGET.vbs`.
Файл `Создать ярлык.vbs` создаёт ярлык на его рабочем столе с локальным путём.
После переноса папки этот файл нужно выполнить повторно. Готовый `.lnk`
с вашего компьютера в архив не входит: абсолютные пути между ПК не переносятся.
Для повторной упаковки используется `PACKAGE_PORTABLE.ps1 -OutputRoot <новая папка>`.
Сборка предназначена для Windows x64; нужны совместимый браузер Chromium и WebView2 Runtime.

## Браузер Windows без расширений

Приложение определяет браузер по умолчанию для HTTPS в Windows и использует CDP
браузеров Chromium: Brave, Chrome, Edge, Vivaldi, Opera, Яндекс Браузер.
Firefox не поддерживается. Некоторые версии Chrome/Edge запрещают управление
стандартным профилем: приложение покажет ошибку, не меняя профиль или защиту.
Для Яндекс Браузера при тайм-ауте обычного профиля предусмотрен резервный запуск:
отдельный постоянный профиль в `.native-data/browser-profiles/yandex`.
В нём нужно один раз войти в музыкальный аккаунт. При закреплении создаётся
отдельный ярлык «Яндекс Браузер — Liquid Music» в меню «Пуск».
Сохранённый музыкальный профиль запускается рядом с обычным браузером;
его восстановление не закрывает обычные окна. Данные обычного профиля не копируются.

Один раз нажмите «Подключить браузер» в настройках с включённым закреплением
в ярлыках. При необходимости браузер корректно перезапустится с восстановлением
вкладок; заранее сохраните ввод на страницах. Если канал уже работает,
перезапуска не будет. «Подключено» означает действующее соединение.

Параметры сохраняются в .native-data/browser-control.json. При запуске виджет
восстанавливает подключение автоматически. Закрытый браузер запускается
с сохранённым каналом. Подходящие ярлыки пользователя на рабочем столе,
панели задач и в меню «Пуск» получают параметры канала. Оригиналы сохраняются
в .native-data/browser-shortcut-backups; manifest.json содержит исходные пути.
Параметры профиля сохраняются. При отсутствии создаётся ярлык в меню «Пуск».

После полного выхода запускайте браузер через обновлённый ярлык или виджет.
Прямой запуск EXE и ссылки из других программ могут запустить браузер без
канала: тогда восстановите подключение в настройках. После смены браузера
по умолчанию потребуется настройка нового браузера. Ассоциации Windows
и общие ярлыки других пользователей не изменяются.

Используются адрес 127.0.0.1 и сохранённый порт. CDP даёт локальным программам
доступ ко всем вкладкам. Приложение управляет музыкальными вкладками вашего
обычного профиля, повторно использует открытые и создаёт отсутствующие в фоне.
Принудительное завершение, копирование профиля и отключение защиты не применяются.
Аккаунты сохраняются в браузере. При выходе из виджета браузер остаётся открытым.

## Голос и игры

Нажмите настроенную клавишу, произнесите «включи трек Династия» и дождитесь
выполнения. Работают также «пауза», «стоп», «продолжи музыку», «следующий трек»,
«предыдущий трек» и «поставь лайк». При выбранном YouTube запускается первый
видеорезультат; при YouTube Music — первый музыкальный результат. При неоднозначном
запросе добавляйте исполнителя к названию.

Перед началом записи звучит короткий сигнал — после него можно говорить.
После распознавания допустимой команды звучит другой, двойной сигнал: команда
принята к выполнению. Это ещё не подтверждение запуска музыки на сайте.

Vosk распознаёт русский локально. Запись в интернет не отправляется и на диск
не сохраняется. Модель `vosk-model-small-ru-0.22` включена в сборку; небольшая
модель может ошибаться в редких названиях и иностранных именах. Используется
микрофон Windows по умолчанию. Нужен разрешённый в Windows доступ настольных
приложений к микрофону; приложение само настройки приватности не меняет.

Голосовая клавиша не вызывает Show/Activate у главного окна и не выводит браузер
поверх игры. Команды передаются браузеру через CDP, без управления системной мышью.
Если включены уведомления, используется отдельное окно WS_EX_NOACTIVATE. Для
полного отсутствия всплывающих окон отключите уведомления и остров в настройках.
Совместимость с эксклюзивным полноэкранным режимом конкретной игры требует
проверки; администраторские права не являются решением проблемы фокуса.

Приложение живёт в трее. Крестик, Esc и Alt+F4 скрывают окно; выход выполняется
через трей или настройки. Повторный запуск открывает существующий экземпляр.
Низкоуровневый хук колёсика только накапливает громкость; браузерные операции
выполняются отдельно и не блокируют хук.

Основной HTML/CSS-интерфейс сохранён. Уведомление и остров реализованы нативными
окнами C#, их оформление отличается от прежней версии. Снимок рабочего стола для
эффекта прозрачности не реализован: доступно оформление стекла внутри окна.

## Сборка и проверки

Нужен .NET 10 SDK. Выполните `powershell -ExecutionPolicy Bypass -File BUILD_NATIVE.ps1`.
NuGet-пакеты: Microsoft.Playwright, Microsoft.Web.WebView2, NAudio, Vosk.
Браузер Playwright отдельно скачивать не нужно: работа выполняется в браузере Windows по умолчанию,
а проверка браузерной логики использует установленный Edge.

Для сборки из исходников русскую модель следует распаковать в
`models/vosk-model-small-ru-0.22`. Официальный архив:
https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
SHA256: `961d5ff98a17f4aa6de69864d0aa71fa5bac682301d2b5d17a3f24c5c99a46d4`.
Модель распространяется на условиях Apache 2.0; README и лицензии библиотек
сохраняются в их исходных пакетах.

Встроенные проверки:

```
native\LiquidMusic.exe --self-test
native\LiquidMusic.exe --browser-test
native\LiquidMusic.exe --ui-test
```

Результаты: `logs/selftest.json`, `logs/browser-selftest.json`, `logs/ui-selftest.json`.
Диагностика: `logs/native.log`. Проверки не записывают микрофон и не входят в аккаунт.
Браузерный тест использует настоящую разметку карточек Яндекса в локальном макете;
проверка с авторизованным аккаунтом нужна отдельно.

На этом компьютере 27.10.2026 выполнена и проверка с текущим профилем Brave:
«ДИНАСТИЯ» — VILLIAN, madk1d запущена, `playing=true`; активным процессом
до и после команды остался RocketLeague. Результат: `logs/live-selftest.json`.
Запись реальной голосовой команды пользователем ещё нужно проверить.
`logs/native-startup.json` подтверждает подключение браузера и регистрацию
сохранённой голосовой клавиши End без конфликтов.
