LIQUID MUSIC — C#

Запуск на этом компьютере: Liquid Music.lnk, START_WIDGET.vbs или native\LiquidMusic.exe.
Сохранённые горячие клавиши: настройки → горячие клавиши. В текущем settings.json
голосовой помощник назначен на End, открытие виджета — F6.

ДЛЯ ОТПРАВКИ ДРУГУ
Отправьте dist\LiquidMusic-Portable.zip целиком.
Друг должен распаковать ZIP и запустить LiquidMusic.exe либо START_WIDGET.vbs.
Для ярлыка на его рабочем столе — «Создать ярлык.vbs» в распакованной папке.
Обычный .lnk с вашего ПК не переносится, поскольку содержит абсолютный путь.
Не отправляйте отдельно один EXE: ему нужны DLL, .playwright, models и ui.

Сборка предназначена для Windows 10/11 x64. Python и установка .NET не нужны.
Совместимый браузер Chromium и Microsoft Edge WebView2 Runtime должны быть установлены.
На новом ПК: настройки → «Подключить браузер», затем вход в свой музыкальный аккаунт.
В архив включены чистые настройки. Ваши данные и подключение к браузеру не копируются.

Подробная документация: README_CSHARP.md.
Сборка из исходников: BUILD_NATIVE.ps1.
Упаковка: PACKAGE_PORTABLE.ps1 -OutputRoot <новая папка>.

Подключение настраивается один раз. Оставьте включённым обновление ярлыков
с резервными копиями: .native-data/browser-shortcut-backups. При запуске
виджет автоматически восстанавливает соединение. Используйте обновлённый
ярлык браузера; прямой запуск EXE может не включить канал управления.
Статус «Подключено» означает действующее соединение. После смены браузера
по умолчанию подключите новый. Firefox не поддерживается; Chrome/Edge могут
запрещать CDP для стандартного профиля.
