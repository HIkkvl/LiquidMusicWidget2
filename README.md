# Liquid Music

Музыкальный виджет и голосовой помощник для Windows 10/11 x64 на C#.
Управляет Яндекс Музыкой и YouTube в браузере без расширений.

## Скачать и запустить

В разделе **Releases** скачайте `LiquidMusic-Portable.zip`, распакуйте целиком
и запустите `LiquidMusic.exe`. Python и отдельная установка .NET не нужны.
Необходимы Microsoft Edge WebView2 Runtime и совместимый браузер Chromium.
Для создания ярлыка выполните `Создать ярлык.vbs` из распакованной папки.

В настройках один раз нажмите **«Подключить браузер»**. Приложение выбирает
браузер по умолчанию Windows. Закрепление в ярлыках сохраняет параметры запуска;
оригиналы ярлыков остаются в резервных копиях. При необходимости браузер
перезапустится: заранее сохраните ввод на страницах. Статус «Подключено»
означает действующее соединение.

Голосовая клавиша по умолчанию — **Num3**, показать или скрыть виджет — **Num0**.
После короткого сигнала скажите: «включи трек Династия».
Двойной сигнал означает, что команда принята. Распознавание русского голоса
выполняется локально с помощью Vosk. Клавиши можно изменить в настройках.

Firefox не поддерживается. Некоторые версии Chrome/Edge ограничивают CDP
для обычного профиля. Приложение не отключает защиту браузера. Локальный
канал управления даёт доступ к вкладкам; используется только `127.0.0.1`.

Если Яндекс Браузер не открывает канал в обычном профиле, виджет автоматически
создаёт отдельный постоянный профиль для музыки. В открывшемся окне войдите
в музыкальный аккаунт один раз. Следующие запуски используют тот же профиль.
При закреплении создаётся отдельный ярлык «Яндекс Браузер — Liquid Music»
в меню «Пуск»; обычные ярлыки для этого профиля не изменяются.

## Сборка

1. Установите .NET 10 SDK.
2. Скачайте [русскую модель Vosk](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip)
   и распакуйте в `models/vosk-model-small-ru-0.22`.
3. Выполните `powershell -ExecutionPolicy Bypass -File BUILD_NATIVE.ps1`.
4. Запустите `native\LiquidMusic.exe`.

Для создания чистого ZIP выполните `PACKAGE_PORTABLE.ps1`.
Исходники не содержат модели, зависимостей сборки, личных настроек,
журналов и данных подключения браузера. Готовый релиз содержит модель и .NET.

Встроенные проверки: `native\LiquidMusic.exe --self-test`, `--browser-test`,
`--ui-test` (для последней закройте обычный экземпляр виджета).
Проверка резервного подключения без модели голоса и установленного Яндекс
Браузера: `native\LiquidMusic.exe --connection-test`.
Проверка веб-интерфейса: установите Playwright через `npm install --no-save playwright`
и выполните `node tests/ui.cjs`; используется установленный Microsoft Edge.

Подробнее: [README_CSHARP.md](README_CSHARP.md).
