# Liquid Music

Музыкальный виджет и голосовой помощник для Windows 10/11 x64 на C#.
Управляет Яндекс Музыкой и YouTube в браузере без расширений.

## Скачать и запустить

В разделе **Releases** скачайте `LiquidMusic-Portable.zip`, распакуйте целиком
и запустите `LiquidMusic.exe`. Python и отдельная установка .NET не нужны.
Необходимы Microsoft Edge WebView2 Runtime и совместимый браузер Chromium.
Для создания ярлыка выполните `Создать ярлык.vbs` из распакованной папки.

В настройках один раз нажмите **«Подключить браузер»**. Приложение выбирает
браузер по умолчанию Windows. Закрепление в ярлыках сохраняет параметры запуска;
оригиналы ярлыков остаются в резервных копиях. При необходимости браузер
перезапустится: заранее сохраните ввод на страницах. Статус «Подключено»
означает действующее соединение.

Голосовая клавиша по умолчанию — **Num3**, показать или скрыть виджет — **Num0**.
После короткого сигнала скажите: «включи трек Династия».
Двойной сигнал означает, что команда принята. Распознавание русского голоса
выполняется локально с помощью Vosk. Клавиши можно изменить в настройках.

В настройках есть «Умный помощник · DeepSeek». Введите свой API-ключ,
включите помощника, нажмите «Сохранить помощника» и «Проверить подключение».
Ключ хранится с шифрованием Windows отдельно от настроек, в `.native-data`;
в Git и portable-архив он не включается. На другом ПК нужен свой ключ.
API-баланс DeepSeek должен быть пополнен; проверка подключения проверяет
доступные модели и достаточность баланса без запроса к языковой модели.

DeepSeek понимает свободные фразы («сделай немного потише», «поставь что-нибудь
спокойное»), уточнения к предыдущим запросам и вопросы о текущем треке.
Простые команды «пауза», «стоп», «следующий трек» выполняются локально.
Для сложных запросов в DeepSeek отправляются распознанный текст, краткая
история текущего сеанса и выбранные поля плеера (название, исполнитель,
громкость, состояние воспроизведения, сервис). Аудио остаётся локальным.
Ответы и уточнения показываются текстом под кнопкой микрофона; озвучки нет.
DeepSeek улучшает понимание текста, а распознавание звука по-прежнему выполняет Vosk.
При отключённом помощнике используется прежний локальный обработчик команд.

Firefox не поддерживается. Некоторые версии Chrome/Edge ограничивают CDP
для обычного профиля. Приложение не отключает защиту браузера. Локальный
канал управления даёт доступ к вкладкам; используется только `127.0.0.1`.

Если Яндекс Браузер не открывает канал в обычном профиле, виджет автоматически
создаёт отдельный постоянный профиль для музыки. В открывшемся окне войдите
в музыкальный аккаунт один раз. Следующие запуски используют тот же профиль.
При закреплении создаётся отдельный ярлык «Яндекс Браузер — Liquid Music»
в меню «Пуск»; обычные ярлыки для этого профиля не изменяются.

Домен Яндекс Музыки выбирается в настройках: «Авто», `.ru`, `.kz` или `.com`.
В режиме «Авто» используется уже открытая музыкальная вкладка, а её домен
запоминается для следующих запусков. Без открытой вкладки и сохранённого домена
приложение открывает `music.yandex.ru`. Поиск остаётся на домене текущей вкладки.

## Сборка

Для проверки своих изменений после клонирования через GitHub Desktop:

1. Установите [.NET 10 SDK для Windows x64](https://dotnet.microsoft.com/download/dotnet/10.0).
   Нужен именно **SDK**; одного Runtime недостаточно.
2. В GitHub Desktop выберите нужную ветку и откройте **Repository → Show in Explorer**.
3. Закройте работающий виджет через меню в трее и запустите `DEV_RUN.bat`.
   Он соберёт текущие исходники, при необходимости скачает русскую модель Vosk
   и запустит `native\LiquidMusic.exe`. При первой сборке нужен интернет.
4. После каждого изменения кода снова запускайте `DEV_RUN.bat`.
   `START_WIDGET.vbs` запускает последнюю сборку без пересборки.

Сборка без запуска: `powershell -NoProfile -ExecutionPolicy Bypass -File BUILD_NATIVE.ps1`.
Совместимый браузер Chromium и Microsoft Edge WebView2 Runtime нужны и при разработке.

Для создания чистого ZIP выполните `PACKAGE_PORTABLE.ps1`.
Исходники не содержат модели, зависимостей сборки, личных настроек,
журналов и данных подключения браузера. Готовый релиз содержит модель и .NET.

Встроенные проверки: `native\LiquidMusic.exe --self-test`, `--browser-test`,
`--ui-test` (для последней закройте обычный экземпляр виджета).
Проверка резервного подключения без модели голоса и установленного Яндекс
Браузера: `native\LiquidMusic.exe --connection-test`.
Проверка помощника без сети и API-ключа: `native\LiquidMusic.exe --assistant-test`.
Проверка веб-интерфейса: установите Playwright через `npm install --no-save playwright`
и выполните `node tests/ui.cjs`; используется установленный Microsoft Edge.
