# Liquid Music

Музыкальный виджет и голосовой помощник для Windows 10/11 x64 на C#.
Поддерживает Яндекс Музыку, YouTube Music, Spotify и SoundCloud. Основной интерфейс — компактный виджет.

## Скачать и запустить

В разделе **Releases** скачайте `LiquidMusic-Portable.zip`, распакуйте целиком
и запустите `LiquidMusic.exe`. Python и отдельная установка .NET не нужны.
Необходим Microsoft Edge WebView2 Runtime. Для Spotify дополнительно нужен установленный Microsoft Edge.
Для создания ярлыка выполните `Создать ярлык.vbs` из распакованной папки.

В настройках откройте вкладку **«Аккаунт»**, выберите домен Яндекс Музыки
и нажмите **«Войти в Яндекс»**. Вход выполняется на странице сервиса внутри
приложения. После входа окно скроется; музыка, поиск и Моя волна работают
в фоне, а на экране остаётся компактный виджет. Кнопка с нотой открывает
аккаунт повторно. Кнопка «Вернуться в виджет» и закрытие окна входа возвращают
плеер в фон.

Сессия хранится в постоянном профиле `%LOCALAPPDATA%\LiquidMusic\Profiles\music-webview` и
восстанавливается после перезапуска и обновления сборки. Настройки аккаунта и домена
хранятся в `%LOCALAPPDATA%\LiquidMusic\settings.json`. При первом запуске новой версии
профили переносятся из `.native-data` текущей или соседних старых сборок Liquid Music;
перед переносом закройте старую версию. Авторизация обычного
браузера не переносится: при первом запуске войдите заново. Пароли вводятся
только на странице сервиса; приложение не добавляет туда свой native API.
Плеер использует отдельное окружение WebView2 с локальным каналом управления
на `127.0.0.1`. Яндекс Музыка, YouTube Music и SoundCloud работают во встроенном WebView2.
Spotify запускается в отдельном фоновом Edge с поддержкой защищённого аудио;
его окно появляется при входе и скрывается после авторизации. Отдельный профиль
Spotify хранится в `%LOCALAPPDATA%\LiquidMusic\Profiles\spotify-edge`; обычный профиль браузера не используется.
Требования сервиса к аккаунту, подписке и защищённому воспроизведению сохраняются.

Выберите сервис кнопками внизу виджета, затем откройте «Настройки → Аккаунт»
для входа. В Spotify, SoundCloud и YouTube Music есть поле поиска по исполнителю
и названию трека; также доступны голосовые команды, пауза, переключение, лайки и громкость.
При смене сервиса виджет приостанавливает предыдущий плеер. Диалоги сайта,
включая выбор cookie, нужно закрыть самостоятельно в окне входа.

Переключение вкладок сразу обновляет интерфейс; запуск плеера выполняется в фоне.
Неактивные встроенные страницы без звука приостанавливаются до возврата.
Библиотека Spotify повторно использует список текущего аккаунта; кнопка ↻
загружает свежий список. Управление колёсиком обрабатывается в отдельном потоке,
чтобы занятое окно виджета не задерживало мышь в Windows.

В Spotify блок «Миксы и плейлисты» загружает плейлисты из библиотеки и рекомендации
с главной страницы вошедшего аккаунта. Кнопка «Добавить плейлист» принимает ссылку
`https://open.spotify.com/playlist/…`, сохраняет карточку в виджете и получает название
с обложкой. Нажатие карточки запускает плейлист в фоне. Добавленные ссылки сохраняются
между перезапусками отдельно для каждого аккаунта; кнопка ↻ перечитывает список.
Если личный плейлист не отдаёт публичное название, ссылка всё равно сохраняется;
название уточняется после запуска плейлиста через вошедший аккаунт.

Голосовая клавиша по умолчанию — **Num3**, показать или скрыть виджет — **Num0**.
После короткого сигнала скажите: «включи трек Династия».
Двойной сигнал означает, что команда принята. По умолчанию распознавание русского
голоса выполняется локально с помощью Vosk. Клавиши можно изменить в настройках.

Настройки разделены на вкладки: «Управление», «Оформление», «Аккаунт»,
«Помощник», «Остров», «Discord» и «Liquid Mood». Переключение вкладок сохраняет
введённые значения до закрытия окна; общая кнопка сохранения доступна снизу.
Кнопка клавиатуры в плеере сразу открывает «Управление».

На главном экране блок «Моя волна» показывает доступные подборки из открытой
вкладки Яндекс Музыки. Нажатие выбирает соответствующую волну на сайте,
без поиска по жанру. Кнопка «Обновить» открывает Мою волну через навигацию сайта
и перечитывает список; при первом подключении он загружается автоматически.
Нужны вход в музыкальный аккаунт и доступ к Моей волне. Список зависит от аккаунта
и может меняться; недоступные карточки отключены. В остальных сервисах блок скрыт.
Выбранная подборка отображается рядом с треком; нажатие на метку возвращает обычную Мою волну.

В настройках есть «Умный помощник · Gemini / DeepSeek». Выберите сервис,
введите его API-ключ, включите помощника, нажмите «Сохранить помощника»
и «Проверить подключение». Ключи сервисов хранятся раздельно с шифрованием
Windows в `.native-data`; в Git и portable-архив они не включаются.
На другом ПК нужен свой ключ. Переключение сервиса очищает историю диалога.
Gemini использует `gemini-3.5-flash-lite` и доступен в рамках Free Tier
с квотами, если это поддерживают регион и аккаунт. Ключ создаётся в
[Google AI Studio](https://aistudio.google.com/api-keys).
Проверка Gemini получает список моделей и отправляет один короткий запрос,
чтобы проверить доступность генерации; этот запрос расходует квоту.
Приложение не переключается на другой сервис при ошибках квоты.
DeepSeek требует пополненный API-баланс; его проверка получает список
моделей и состояние баланса без запроса к языковой модели.

Помощник понимает свободные фразы («сделай немного потише», «поставь что-нибудь
спокойное»), уточнения к предыдущим запросам и вопросы о текущем треке.
Простые команды «пауза», «стоп», «следующий трек» выполняются локально.
Для сложных запросов в выбранный сервис отправляются распознанный текст, краткая
история текущего сеанса и выбранные поля плеера (название, исполнитель,
громкость, состояние воспроизведения, сервис). Аудио остаётся локальным,
пока отдельно не включён режим распознавания записи через Gemini.
На бесплатном тарифе Gemini Google может использовать данные для улучшения
продуктов. Учитывайте [условия Free Tier](https://ai.google.dev/gemini-api/docs/pricing).
Ответы и уточнения показываются текстом под кнопкой микрофона; озвучки нет.
В локальном режиме звук распознаёт Vosk, а модель дополняет понимание текста.
При отключённом помощнике используется прежний локальный обработчик команд.

Для английской и смешанной речи выберите Gemini и включите отдельный переключатель
«Русский + English: распознавать запись через Gemini», затем сохраните помощника.
Короткая запись отправляется Google; она собирается в памяти и не сохраняется
в файл или Git. После распознавания текст передаётся обработчику намерений.
Этот режим расходует квоту Gemini: обычно один запрос на распознавание и один
на понимание просьбы. Локально распознанные простые команды не отправляют запись.
При выключенном режиме или другом сервисе звук остаётся локальным.

В «Подсказках имён артистов» можно указать оригинальное написание и произношение,
например `madk1d (мэд кид, мэдкид, мэт кид)`. Подсказки помогают со сценическими
именами и цифрами. Названия `Rehab` и `РЕХАБ` сопоставляются при поиске и проверке
воспроизведения; указанный исполнитель тоже должен совпасть. Если речь не разобрана,
помощник просит повторить фразу. Качество зависит от микрофона и произношения.
Словесные даты тоже сопоставляются с цифрами: например «madk1d первого мая»
находит «1 мая» — madk1d, CUPSIZE. Это применяется и к выбору карточки,
и к подтверждению воспроизведения. При отсутствии совпадения приложение
сообщает об этом отдельно от недоступной кнопки запуска.

Домен Яндекс Музыки выбирается в настройках: «Авто», `.ru`, `.kz` или `.com`.
В режиме «Авто» используется уже открытая музыкальная вкладка, а её домен
запоминается для следующих запусков. Без открытой вкладки и сохранённого домена
приложение открывает `music.yandex.ru`. Поиск остаётся на домене текущей вкладки.

## Сборка

Для проверки своих изменений после клонирования через GitHub Desktop:

1. Установите [.NET 10 SDK для Windows x64](https://dotnet.microsoft.com/download/dotnet/10.0).
   Нужен именно **SDK**; одного Runtime недостаточно.
2. В GitHub Desktop выберите нужную ветку и откройте **Repository → Show in Explorer**.
3. Закройте работающий виджет через меню в трее и запустите `DEV_RUN.bat`.
   Он соберёт текущие исходники, при необходимости скачает русскую модель Vosk
   и запустит `native\LiquidMusic.exe`. При первой сборке нужен интернет.
4. После каждого изменения кода снова запускайте `DEV_RUN.bat`.
   `START_WIDGET.vbs` запускает последнюю сборку без пересборки.

Сборка без запуска: `powershell -NoProfile -ExecutionPolicy Bypass -File BUILD_NATIVE.ps1`.
Microsoft Edge WebView2 Runtime нужен и при разработке.

Для создания чистого ZIP выполните `PACKAGE_PORTABLE.ps1`.
Исходники не содержат модели, зависимостей сборки, личных настроек,
журналов и данных подключения браузера. Готовый релиз содержит модель и .NET.

Встроенные проверки: `native\LiquidMusic.exe --self-test`, `--browser-test`,
`--ui-test` (для последней закройте обычный экземпляр виджета).
Скрытый WebView2 и сохранение сессии проверяются через `--embedded-test` на локальной
странице без личного аккаунта. `--embedded-site-test` проверяет загрузку Яндекс Музыки
в чистом тестовом профиле; защищённое воспроизведение требует отдельной проверки после входа.
`--services-test` проверяет отдельный Edge для Spotify, поддержку DRM, скрытый SoundCloud,
поиск, метаданные, воспроизведение, переключение, лайки и громкость на локальных тестовых треках.
Проверка резервного подключения без модели голоса и установленного Яндекс
Браузера: `native\LiquidMusic.exe --connection-test`.
Проверка помощника без сети и API-ключа: `native\LiquidMusic.exe --assistant-test`.
Проверка веб-интерфейса: установите Playwright через `npm install --no-save playwright`
и выполните `node tests/ui.cjs`; используется установленный Microsoft Edge.
