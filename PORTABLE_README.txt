LIQUID MUSIC — C# PORTABLE (Windows x64)

КАК ЗАПУСТИТЬ НА ДРУГОМ КОМПЬЮТЕРЕ
1. Распакуйте ZIP целиком в обычную папку с правом записи, например на рабочий стол.
   Не запускайте приложение внутри ZIP и не переносите отдельно один EXE.
2. Запустите LiquidMusic.exe или START_WIDGET.vbs в распакованной папке.
   Папки .playwright, models, ui и DLL нужны приложению — оставьте их рядом с EXE.
3. Для ярлыка на рабочем столе дважды нажмите «Создать ярлык.vbs».
   Он создаст правильный путь для ЭТОГО компьютера. При переносе папки выполните
   этот файл повторно. Готовые .lnk с чужого компьютера переносить не нужно.

ТРЕБОВАНИЯ
• Windows 10/11 x64. Эта сборка не предназначена для macOS, Linux и Windows x86.
• Совместимый браузер Chromium по умолчанию Windows и Microsoft Edge WebView2 Runtime.
  Brave: https://brave.com/download/
  WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
• Python и отдельная установка .NET не требуются — .NET входит в сборку.
• Интернет и аккаунт/подписка на выбранном музыкальном сервисе.

ПЕРВАЯ НАСТРОЙКА
Откройте настройки виджета → «Подключить браузер». Сначала сохраните несохранённый
ввод в браузере: Браузер при необходимости перезапустится с восстановлением вкладок и локальным
каналом управления. Расширения не нужны. Канал даёт локальный доступ к вкладкам;
не открывайте его порт в сети. Аккаунты друга и его профиль браузера используются
на его компьютере; чужие аккаунты и параметры подключения не включены в архив.

КЛАВИШИ ПО УМОЛЧАНИЮ
Num0 — показать / скрыть виджет.
Num3 — голосовая команда (Num Lock включён).
Num6 / Num4 — следующий / предыдущий трек.
Num5 — пауза / продолжить. Num2 — стоп. Num1 — лайк.
Все клавиши можно изменить в настройках.

После короткого сигнала скажите «включи трек Династия».
Двойной сигнал означает, что команда распознана и принята к выполнению.
Голос распознаётся локально; запись не отправляется в интернет.
Доступ настольных приложений к микрофону должен быть разрешён в Windows.
Голосовая клавиша не открывает окно виджета поверх игры.

Сборка поставляется с чистыми настройками. После запуска настройки и служебные
данные создаются в этой папке. Для отправки следующему человеку используйте
исходный чистый ZIP, а не папку со своими данными после использования.

Подключение настраивается один раз. Оставьте включённым обновление ярлыков
с резервными копиями: .native-data/browser-shortcut-backups. При запуске
виджет автоматически восстанавливает соединение. Используйте обновлённый
ярлык браузера; прямой запуск EXE может не включить канал управления.
Статус «Подключено» означает действующее соединение. После смены браузера
по умолчанию подключите новый. Firefox не поддерживается; Chrome/Edge могут
запрещать CDP для стандартного профиля.

ДОМЕН ЯНДЕКС МУЗЫКИ
В настройках выберите «Авто», music.yandex.ru, music.yandex.kz или music.yandex.com.
«Авто» использует открытую музыкальную вкладку и запоминает её домен.
Если вкладка ещё не открывалась, используется music.yandex.ru.
Для Казахстана можно выбрать music.yandex.kz вручную. Поиск использует
домен текущей музыкальной вкладки.

УМНЫЙ ПОМОЩНИК GEMINI / DEEPSEEK (ПО ЖЕЛАНИЮ)
В настройках выберите Gemini или DeepSeek, введите ключ выбранного сервиса,
включите помощника и сохраните. Ключи хранятся раздельно с шифрованием Windows.
Gemini доступен в рамках Free Tier с квотами и региональными ограничениями;
проверка подключения делает один короткий запрос и расходует квоту.
Для DeepSeek нужны средства на API-балансе; проверка проверяет этот баланс.
Нужен интернет. Ключи не переносятся с другими пользователями Windows.
Сложные фразы, короткая история запросов и сведения о текущем треке отправляются
в выбранный сервис. На Gemini Free Tier Google может использовать данные
для улучшения продуктов. Аудио распознаётся локально. Простые команды остаются локальными.
Помощник понимает свободные формулировки и уточнения; ответы показаны текстом.
